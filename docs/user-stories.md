
# User Stories

## Movement
As a player, I want to move around the dungeon using WASD so I can explore the map.

## Combat
As a player, I want to attack the skeleton so I can survive.

## Key
As a player, I want to pick up the key so I can unlock the exit door.

## Winning
As a player, I want to escape through the door so I can finish the game.

## Saving
As a player, I want to save my game so I can continue later.

## Loading
As a player, I want to load my saved game so I don't lose my progress.

## Graphical interface
As a player, I want to see the dungeon and my health so the game is easier to play.
